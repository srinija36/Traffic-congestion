# Traffic Congestion Prediction Using Machine Learning
📖 Overview

Traffic congestion is a significant challenge in modern cities, affecting travel time, fuel consumption, and environmental sustainability. This project uses Machine Learning techniques to predict traffic congestion levels based on historical traffic and weather-related data.

The goal is to analyze traffic patterns and provide data-driven insights that can support efficient traffic management and smart city initiatives.

# Objectives
Analyze traffic and weather datasets.
Identify factors influencing traffic congestion.
Build a predictive Machine Learning model.
Evaluate model performance and accuracy.
Generate insights for traffic management and planning.

The developed model successfully predicts traffic congestion levels using traffic and weather conditions, demonstrating the effectiveness of Machine Learning in transportation analytics.
